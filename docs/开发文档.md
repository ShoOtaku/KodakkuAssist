## 1. 脚本是什么

KodakkuAssist（可达鸭）脚本是一个 **C# 源文件（.cs）**，由插件在游戏内通过 Roslyn 动态编译加载。脚本由三个部分组成：

- **类 + `[ScriptType]` 特性**：声明脚本名称、GUID、适用副本等元信息
- **`Init(ScriptAccessory)` 方法**：脚本加载时调用一次，用于初始化状态与清理
- **若干 `[ScriptMethod]` 方法**：事件订阅处理器，游戏事件满足条件时被调用

脚本不属于插件，不需要 manifest、不打包 DLL，直接在插件设置界面添加 `.cs` 文件路径或从在线库下载即可。

**加载机制**：

1. 插件通过 Roslyn 编译 `.cs` 源码为内存程序集
2. 查找带有 `ScriptTypeAttribute` 的类，实例化
3. 调用类的 `Init` 方法（`Init(ScriptAccessory)` 签名，可省略）
4. 扫描所有带 `ScriptMethodAttribute` 的方法，注册为事件处理器
5. 扫描所有带 `UserSettingAttribute` 的属性，注册为用户设置项
6. 每个事件处理器在线程池线程中执行，异常不会中断插件（自动捕获并打日志）

## 3. 脚本基本结构

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Numerics;
using KodakkuAssist.Data;
using KodakkuAssist.Module.Draw;
using KodakkuAssist.Module.Draw.Manager;
using KodakkuAssist.Module.GameEvent;
using KodakkuAssist.Module.GameOperate;
using KodakkuAssist.Script;
using Newtonsoft.Json;

namespace MyScriptNamespace
{
    [ScriptType(
        name: "我的副本脚本",
        territorys: [1122],                          // 生效副本 ID，[] 表示全副本生效
        guid: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx", // 必须唯一，更新脚本时保持不变
        version: "0.0.1",
        author: "我",
        note: "脚本说明",
        updateInfo: "更新日志"
    )]
    public class MyScript
    {
        // 实例状态（脚本实例在加载期间一直存在）
        private int _phase = 0;
        private uint _bossId = 0;
        private readonly bool[] _drawn = new bool[20]; // 绘图去重标记

        // Init：脚本加载/重载时调用，用于重置状态、清理绘图
        public void Init(ScriptAccessory accessory)
        {
            _phase = 0;
            _bossId = 0;
            Array.Clear(_drawn);
            accessory.Method.RemoveDraw(".*");     // 清掉旧绘图
            accessory.Method.MarkClear();          // 清掉标记（可选）
        }

        [ScriptMethod(name: "记录BOSS", eventType: EventTypeEnum.StartCasting,
            eventCondition: ["ActionId:40972"], userControl: false)]
        public void BossRecord(Event @event, ScriptAccessory accessory)
        {
            if (_bossId != 0) return;
            _bossId = @event.SourceId;             // SourceId 属性是 ulong（十六进制字符串解析）
        }

        [ScriptMethod(name: "分摊提示", eventType: EventTypeEnum.StartCasting,
            eventCondition: ["ActionId:regex:^(4099[02])$"], userControl: true)]
        public void StackHint(Event @event, ScriptAccessory accessory)
        {
            var dp = accessory.Data.GetDefaultDrawProperties();
            dp.Name = "分摊提示";
            dp.Scale = new Vector2(6);
            dp.Owner = _bossId;
            dp.TargetResolvePattern = PositionResolvePatternEnum.PlayerNearestOrder;
            dp.TargetOrderIndex = 1;
            dp.Color = accessory.Data.DefaultDangerColor;
            dp.DestoryAt = 5000;
            accessory.Method.SendDraw(DrawModeEnum.Default, DrawTypeEnum.Circle, dp);
        }
    }
}
```

## 4. ScriptType 特性（脚本元信息）

```csharp
[AttributeUsage(AttributeTargets.Class)]
public class ScriptTypeAttribute : Attribute
{
    public string Name { get; }                 // 脚本显示名
    public HashSet<uint> Territorys { get; }    // 生效副本 ID 集合
    public string Guid { get; }                 // 脚本唯一标识（更新时保持不变）
    public string Version { get; }              // 版本号字符串
    public string Author { get; }               // 作者
    public string Note { get; }                 // 脚本说明（可多行）
    public string UpdateInfo { get; }           // 更新信息（可多行）
}
```

参数顺序与默认值：

```csharp
public ScriptTypeAttribute(
    string guid,
    string name = "Default Script",
    uint[]? territorys = null,
    string version = "0.0.0.1",
    string author = "Unknown",
    string note = "",
    string updateInfo = "")
```

要点：

- **`territorys` 为空 `[]` 表示所有副本生效**（如调试脚本）
- **`guid` 是脚本的"身份证"**：插件用它做更新检测、用户设置持久化。**发布后永远不要改**；否则会丢失用户设置并被当作新脚本
- `version`、`note`、`updateInfo` 支持用 `const string` 加 raw string（`"""..."""`）组织多行文本（社区常用写法）

社区常见写法（多行文档字符串）：

```csharp
private const string NoteStr =
    """
    第一行说明
    第二行说明
    """;

[ScriptType(name: Name, territorys: [1243], guid: "45fff289-...",
    version: Version, author: "Usami", note: NoteStr)]
```

## 5. ScriptMethod 特性（事件订阅）

```csharp
[AttributeUsage(AttributeTargets.Method)]
public class ScriptMethodAttribute : Attribute
{
    public EventTypeEnum EventType { get; set; }          // 监听的事件类型
    public string Name { get; set; }                      // 方法显示名（界面/日志用）
    public Dictionary<string, string> EventCondition { get; set; } // 事件属性匹配条件
    public bool UserControl { get; set; }                 // 是否允许用户在界面关闭此方法
    public uint Suppress { get; set; }                    // 同一方法触发间隔抑制（毫秒）
}
```

```csharp
[ScriptMethod(
    name: "方法名",
    eventType: EventTypeEnum.StartCasting,
    eventCondition: ["ActionId:40972"],   // 键:值 条件数组
    userControl: false,                    // false = 用户不能在界面关闭
    suppress: 1000                         // 可选：1 秒内最多触发一次
)]
public void MethodName(Event @event, ScriptAccessory accessory) { ... }
```

### 事件条件（EventCondition）语法

数组每项为 `"键:值"`，**所有条件同时满足**（AND）才触发方法：

| 写法 | 含义 |
|------|------|
| `"ActionId:40972"` | 精确匹配（字符串相等） |
| `"ActionId:regex:^(4099[02])$"` | 正则匹配（值以 `regex:` 开头，**6 个字符前缀**） |
| `"Id:0017"` | 目标图标 ID（十六进制字符串精确匹配） |
| `"Type:Echo"` | 聊天类型 |
| `"Message:=TST"` | 聊天消息内容精确等于 `=TST`（`=` 是内容的一部分，不是语法） |

> 匹配逻辑：`pair.Value.StartsWith("regex:")` 则截取第 7 位起作为正则模式，否则 `value == pair.Value` 精确比较。

常用条件键（具体键名见 [第 7 节](#7-事件类型与属性键全集)）：

- `ActionId` — 技能 ID
- `StatusID` — 状态 ID
- `Id` — 目标图标 ID / 环境控制 ID
- `SourceId` / `TargetId` — 源/目标实体 ID（十六进制字符串）
- `SourceDataId` / `DataId` — 源/目标 DataId
- `Index` / `TargetIndex` — 序号（1 起）
- `Type` — 聊天类型
- `Message` — 聊天消息内容
- `DirectorId` + `State` — 副本演出控制（Director 事件）

### userControl 语义

- `true`（默认）：用户可以在插件设置界面勾选启用/禁用此方法
- `false`：方法始终启用，界面上不可关闭（用于"数据记录"这类后台逻辑）

### Suppress（节流）

同一方法在 `Suppress` 毫秒内只触发一次，用于高频事件（如 EnvControl 每帧事件）去重：

```csharp
[ScriptMethod(name: "...", eventType: EventTypeEnum.EnvControl, suppress: 200)]
```

## 6. 事件模型 Event

```csharp
public class Event
{
    public DateTime DateTime { get; }              // 事件发生时间
    public EventTypeEnum Type { get; set; }        // 事件类型
    public string ActLog { get; set; }             // ACT 日志行格式文本
    public string Info { get; set; }               // 附加信息（属性对格式）
    public string this[string name] { get; set; }  // 属性键值访问（不存在返回 ""）
    public ulong SourceId { get; }                 // 源实体 ID（十六进制解析）
    public ulong TargetId { get; }                 // 目标实体 ID
    public Vector3 SourcePosition { get; }         // 源位置（JSON 反序列化）
    public Vector3 TargetPosition { get; }         // 目标位置
    public Vector3 EffectPosition { get; }         // 效果位置
    public float SourceRotation { get; }           // 源朝向（弧度）
    public float TargetRotation { get; }           // 目标朝向
    public uint Id { get; }                        // Id 属性（图标/环境控制 ID）
    public uint ActionId { get; }                  // 技能 ID
    public uint StatusId { get; }                  // 状态 ID
    public uint StatusStackCount { get; }          // 状态层数
    public uint StatusParam { get; }               // 状态参数
    public bool Has(string name);                  // 是否包含某属性
    public bool TryGet(string name, out string value);
    public void AddProperties(string name, string value);
}
```

**核心用法：`@event["键名"]` 取字符串值，不存在时返回 `""` 而不是抛异常**。

```csharp
// 推荐的安全取值方式：
if (!ulong.TryParse(@event["SourceId"], System.Globalization.NumberStyles.HexNumber, null, out var sid))
    return;

var aid = (uint)JsonConvert.DeserializeObject<uint>(@event["ActionId"]); // 或 uint.TryParse
```

> 注意：`SourceId`、`TargetId` 是**十六进制字符串**（如 `"4000123A"`），且对象 ID 可能是 64 位（GameObjectId 含类型位）；`ActionId`、`StatusID`、`Id` 是**十进制字符串**。解析时务必用 `NumberStyles.HexNumber` 处理 ID 类字段。

## 8. ScriptAccessory（脚本执行入口）

每个事件处理器和 `Init` 都会收到 `ScriptAccessory`，它是脚本访问插件能力的唯一入口，包含三个子对象：

```
ScriptAccessory
├── Data     (DataAccessory)    — 游戏数据读取
├── Method   (MethodAccessory)  — 操作执行（绘图/发消息/TTS/标记…）
└── Log      (LogAccessory)     — 日志
```

### 8.1 Data（数据读取）

```csharp
public class DataAccessory
{
    public ReadOnlyDictionary<ulong, ReadOnlyCollection<ulong>> EnmityList { get; } // 仇恨列表
    public List<uint> PartyList { get; }                      // 队伍成员 EntityId 列表（按职业排序）
    public Vector4 DefaultDangerColor { get; }                // 插件默认危险色
    public Vector4 DefaultSafeColor { get; }                  // 插件默认安全色
    public IObjectTable Objects { get; }                      // 场景对象表
    public uint Me { get; }                                   // 自己的 EntityId
    public IPlayerCharacter? MyObject { get; }                // 自己的对象
    public DrawPropertiesEdit GetDefaultDrawProperties()      // 获取默认绘图属性（见绘图章节）
}
```

**对象接口（IObjectTable / IGameObject）**：

```csharp
public interface IGameObject
{
    SeString Name { get; }          // 名字（ToString() 取文本）
    ulong GameObjectId { get; }     // 完整对象 ID（含类型位，十六进制）
    uint EntityId { get; }          // 实体 ID（32 位）
    uint DataId { get; }            // 数据 ID（NPC/对象类型 ID）
    uint OwnerId { get; }
    ObjectKind ObjectKind { get; }  // 对象类型（Player/Npc/EventObj...）
    bool IsDead { get; }
    bool IsTargetable { get; }
    Vector3 Position { get; }
    float Rotation { get; }
    float HitboxRadius { get; }
    ulong TargetObjectId { get; }
    IGameObject? TargetObject { get; }
}

public interface IObjectTable : IEnumerable<IGameObject>
{
    IPlayerCharacter? LocalPlayer { get; }
    IGameObject? SearchById(ulong gameObjectId);     // 用完整对象 ID 查
    IGameObject? SearchByEntityId(uint entityId);    // 用 EntityId 查
}

public interface ICharacter : IGameObject
```

## 9. 绘图 API

### 9.1 绘图模式与类型

```csharp
public enum DrawModeEnum { Default, Imgui, Vfx }
public enum DrawTypeEnum { Circle, Displacement, Donut, Fan, HotWing, Line, Rect, SightAvoid, Straight, Arrow }
```

| 模式 | 说明 |
|------|------|
| `Default` | 游戏内 3D 绘制（战斗地形上显示）——副本机制指示**首选** |
| `Imgui` | 屏幕空间 2D 覆盖绘制——指路箭头、玩家屏幕指引 |
| `Vfx` | 游戏内 VFX 特效（配合 `VfxMethod`） |

| 类型 | 说明 | 关键属性 |
|------|------|---------|
| `Circle` | 圆形 | `Scale` = 半径 |
| `Fan` | 扇形 | `Scale` = 半径，`Radian` = 弧度角 |
| `Donut` | 圆环 | `Scale` = 外径，`InnerScale` = 内径 |
| `Rect` | 矩形 | `Scale` = (宽, 长) |
| `Straight` | 直线/条 | `Scale` = (宽, 长)，`Rotation` 朝向 |
| `Displacement` | 位移圈（移动范围指示，屏幕指引用） | 常配 `Imgui` 模式 |
| `Line` | 连线 | `Imgui` 模式，`TargetObject`/`TargetPosition` |
| `Arrow` | 箭头 | `Imgui` 模式，指路箭头 |
| `SightAvoid` | 视线回避（背对区域） | 面向判定 |

### 9.3 标准绘图流程

```csharp
var dp = accessory.Data.GetDefaultDrawProperties();  // 获取默认（Name=GUID, Scale=(5,5), Radian=π/2, 危险色, DestoryAt=5000）
dp.Name = "机制名";                                   // 必须给有意义的名字（移除靠它）
dp.Scale = new Vector2(6);
dp.Owner = bossId;                                    // 跟随目标
dp.Color = accessory.Data.DefaultDangerColor;
dp.DestoryAt = 8000;
accessory.Method.SendDraw(DrawModeEnum.Default, DrawTypeEnum.Circle, dp);
```

**绘图位置解析（社区高频模式）**：

```csharp
// 1. 固定在 Owner 身上
dp.Owner = bossId;

// 2. 固定坐标
dp.Position = new Vector3(100, 0, 100);

// 3. 指向 Boss 的第 1 近玩家（分摊/点名）——最常用
dp.Owner = bossId;
dp.TargetResolvePattern = PositionResolvePatternEnum.PlayerNearestOrder;
dp.TargetOrderIndex = 1;

// 4. 指向 Boss 的第 2 远玩家
dp.Owner = bossId;
dp.TargetResolvePattern = PositionResolvePatternEnum.PlayerFarestOrder;
dp.TargetOrderIndex = 2;

// 5. 双对象连线
dp.Owner = sourceId;
dp.TargetObject = targetId;
accessory.Method.SendDraw(DrawModeEnum.Imgui, DrawTypeEnum.Line, dp);
```

**移除绘图**：

```csharp
accessory.Method.RemoveDraw(".*");          // 移除全部
accessory.Method.RemoveDraw("P1_机制");      // 按名字（正则）移除——注意精确匹配时用正则锚定
accessory.Method.RemoveDraw("P1_机制.*");    // 前缀匹配推荐写法
```

> 移除用**正则表达式**匹配 `Name`。常用技巧：所有同机制绘图共用一个前缀（如 `"P1_八方雷火"`），结束时 `RemoveDraw("P1_八方雷火.*")` 一次清掉。

**技能预警填充**：

```csharp
dp.ScaleMode |= ScaleMode.ByTime;  // 随时间从中心填充，用于读条预警
```

**延迟出现**：

```csharp
dp.Delay = 6000;      // 6 秒后才出现
dp.DestoryAt = 8000;  // 出现后存在 8 秒
```

**DangerColor 语义**（社区惯例）：

- `DefaultDangerColor`：危险区域（红）
- `DefaultSafeColor`：安全区/站位（绿）

## 10. 用户设置 UserSetting

```csharp
[AttributeUsage(AttributeTargets.Property)]
public class UserSettingAttribute : Attribute
{
    public string Note { get; set; }   // 设置项说明
}
```

在脚本类中声明**公开可写属性**并打上 `[UserSetting]` 即可出现在插件设置界面：

```csharp
[UserSetting("是否开启屏幕文字提示")]
public bool EnableText { get; set; } = true;

[UserSetting("是否开启TTS语音提示")]
public bool EnableTTS { get; set; } = true;

[UserSetting("常用危险色")]
public ScriptColor DangerColor { get; set; } = new() { V4 = new Vector4(1, 0, 0, 1) };

[UserSetting("指路箭头粗细")]
public int ArrowScale { get; set; } = 1;

[UserSetting("指挥模式")]
public bool CommandMode { get; set; } = false;
```

要点：

- 支持类型：`bool`、`int`、`float`、`string`、`ScriptColor`、枚举等（JSON 序列化持久化）
- **属性必须是实例属性（或 static 均可，社区两种都有）**，插件按属性名持久化到 `Guid + 属性名`
- **给每个设置一个默认值**，用户改过会覆盖
- 设置以脚本 GUID 为命名空间持久化，**改 GUID 会丢设置**
- 界面分组可用 `[UserSetting("-----全局设置-----")]` 这样的分隔名（社区做法）
- 设置值在脚本内直接读属性即可，事件处理器每次读取最新值

### 11.1 阶段机（Phase Machine）

### 11.6 事件处理器中的异步/延时

事件处理器在**线程池线程**执行，可以 `await`：

